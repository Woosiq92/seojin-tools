# 서진 수업 도구

특수학교 수업에서 바로 쓰는 웹 도구 모음입니다. 파일 한 장이라 설치가 필요 없고, 인터넷 없이도 파일을 내려받아 열면 그대로 돌아갑니다.

## 손끝 연습

터치스크린 · 마우스 · 키보드 기본 조작을 학교급별 5단계씩 연습합니다.

- 열기: https://woosiq92.github.io/seojin-tools/sonkkeut/
- 내려받아 쓰기: `sonkkeut/index.html` 을 저장한 뒤 크롬으로 열면 됩니다.

학생 이름이나 학습 기록은 저장하지 않습니다. 교사가 고른 설정(소리·크기·횟수 등)만 그 컴퓨터의 브라우저에 남습니다. 서버로 나가는 정보는 없습니다.

전자칠판에 띄우고 학생이 나와서 만지는 방식을 생각하고 만들었습니다. 활동 중 왼쪽 위 ← 를 1초 누르면 단계 고르기 화면으로 돌아갑니다.
